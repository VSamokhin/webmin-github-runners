GitHub Actions Runners

This module shows the self-hosted GitHub Actions runners of the repositories and organizations you watch: which are busy (and with which job), which are idle and which are offline. It also lists jobs waiting for a runner, and flags jobs that no online runner can take because their labels do not match.

The data comes from ghrunners-collector, a small service that polls the GitHub API and writes a JSON status file. The module only reads that file, so it needs no GitHub token. Set the file path under Module Config.

The page refreshes itself; the interval is also set under Module Config.
